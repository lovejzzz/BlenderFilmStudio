# RC3 C1：在产品修改前纠正 D1 坐标语义

RC3 v0.1 发布后的静态几何检查发现，D1 把 RC2 的
`pathOffsetFromHingeMeters=0.62` 当成了世界坐标 `Y=0.62`。门洞宽 0.92 m，
半宽只有 0.46 m，因此球心已经横向超出门洞 0.16 m，尚未计入 0.16 m 球半径。
这不是 Bullet 参数问题，而是初始条件坐标系抄写错误。

发现时产品源码修改、Blender 启动和渲染均为 0。v0.1 与 D1 v0.1 原样保留。
C1 只把三个 D1 初始位置改为已验收 RC2 量纲推导：球心
`[-2.37357276, 0.169, 0.67938984]`、斜坡中心 `[-1.45, 0, 0]`、门体中心
`[0.91, 0, 0.55]`。H1、动作图结构、质量/摩擦/恢复系数、关系、镜头规则、
验收阈值和资源上限全部不变。

这次纠正的意义是拒绝“先跑起来，再手动把球挪到能撞上的地方”。初始几何
必须在求解前自洽；求解后的结果仍完全交给 Blender Bullet。
