# Personal Film Studio 0.1.4

双击 **Open Film Studio.command** 打开夜景磁带机工程，或双击 **Open Little Gravity.command** 打开日光动力雕塑工程。使用这台 Mac 已验证的 Film Studio Engine，无需安装新引擎。

工作室在画面右侧的 **Film Studio** 标签。点 **New film from this…** 创建自己的片名，然后调整镜头、用中文向 AI 导演提建议、预览画面、保存版本，并导出自己的影片。

详细步骤见 **开始使用.md**。成片放在 **movies/**；可编辑工程放在 **projects/**。新版本保存在你的 **Movies/Personal Film Studio/** 文件夹中。

| 影片 | 长度 | 内容 |
| --- | --- | --- |
| The Last Signal | 18 秒 / 4 个镜头 | 夜晚的磁带机，冷暖光、卷盘微距、跳动的电平表与停止的机械 |
| A Little Gravity | 16 秒 / 4 个镜头 | 日光中的金属球、坡道与八块多米诺，真实刚体运动和动作剪辑 |

两部成片均为1920×818、24fps，包含原创合成配乐与音效。它们是可编辑的电影感短片练习；当前 AI 支持机位、焦距、对焦、剪切与色调调整。任意人物表演、复杂场景生成和液体制作仍需后续扩展。

本地启动文件依赖同一项目的 studio 源码和现有引擎路径，请保持项目文件夹位置。AI 导演使用你现有 Codex 登录和账户额度。

声音已做完整解码、响度、峰值和事件时点检查；当前工具无法听取音频，因此没有声称完成主观听审。
