# Pinned ACES 2 OCIO configuration

`cg-config-v4.0.0_aces-v2.0_ocio-v2.5.ocio` is serialized from the OpenColorIO 2.5 built-in config with the same name using Blender 5.2.0 LTS and `blender/export_ocio_config.py`.

The upstream configuration is OpenColorIO-Config-ACES v4.0.0 for ACES 2.0, released under BSD-3-Clause. `source.json` records the upstream release, commit, library version, default display/view, and exact serialized-file SHA-256.

The repository copy is pinned for reproducible research. Updating Blender, OpenColorIO, or the upstream config requires a new hash and a new pixel experiment.
